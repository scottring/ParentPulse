## Relish UI changes

For every Relish UI change, read `docs/relish-design/RELISH-DESIGN.md` and look at the reference board for the affected screen in `docs/relish-design/boards/`. Reuse the existing Relish components. Keep navigation, audience, and writing and sharing behavior consistent with the guide, and stay within the requested scope. Review the result on desktop, a standard phone, and iPhone Duo open and closed, and call out any deliberate departure from the references.

`docs/design_handoff_relish_redesign/` is an earlier direction; where it disagrees, the guide above wins.
